# 第十二阶段 可选联网搜索（后端与页面已接入，真实服务调用通过）

> [项目总览](../README.md) · [上一阶段](第十一阶段-用户权限与会话持久化.md)

## 阶段目标与当前状态

当前库没有 `ready` 文档时，用户可在网页主动勾选“联网搜索”并提问。后端用独立的 Responses API `web_search` 调用，只发送当前问题；网页回答和来源写入当前会话，刷新后仍可读取。默认知识库模式仍不联网，空库问答仍返回 409。离线回归及两次真实服务调用已通过；尚未完成浏览器端到端验收，因此本阶段是**部分完成**。原定的异步索引、评测、容器化、安全加固和展示工作顺延为阶段 13～17。

## 交互与数据边界

1. 当前库没有 `ready` 文档时，页面继续提示上传资料；`failed` 文档保留重试索引入口。联网复选框只在空库显示，由用户主动勾选。已有 `ready` 文档的库和旧版全库会话不能使用此模式。
2. 联网回答标明“网页来源”，把模型返回的引用位置显示为可点击链接，并列出网页标题与 URL；知识库回答继续使用本地文档片段。网页结果不自动写入知识库或 Qdrant。
3. 搜索请求只包含当前问题，不携带私有文档或整段会话历史。后端按登录用户验证会话及知识库归属，网页来源类型、链接和引用位置随回答写入 MySQL；搜索失败不写入半轮消息。
4. “知识库为空”和“已有文档但没有相关证据”仍是不同情况。本阶段只实现空库显式联网；后者的相关性判断与可选联网入口留待评测后决定。

## 实现与接口

- `src/chat/web_search.py` 调用 OpenAI Responses API 的 `web_search` 工具，要求实际搜索并提取 `url_citation`。没有回答或有效网页来源时返回明确错误，不接受无来源答案。采用[官方 Web Search 文档](https://developers.openai.com/api/docs/guides/tools-web-search)所述的引用结构。
- `POST /chat/sessions/{id}/messages` 原请求 `{"message":"..."}` 保持知识库模式；显式联网使用 `{"message":"...","mode":"web"}`。请求仍需登录 Cookie 与 `X-CSRF-Token`。仅允许本人且所绑定知识库没有 `ready` 文档的会话；未授权返回 404，已有可检索文档返回 409。
- 联网响应的 `evidence` 包含 `source_type=web`、`rank`、`title`、`url`，`metadata` 包含 `mode=web`、模型和引用位置 `citations`。网页只接受 HTTP(S) 来源链接。成功回答使用现有 `chat_messages` 保存，不新增数据库表。
- 页面在空库时显示联网复选框，回答正文中的引用与来源列表均可点击；浏览器创建链接时也只接受 HTTP(S) URL。网页引用与本地片段采用不同样式，刷新后由会话历史恢复。
- `WEB_SEARCH_MODEL` 可在 `.env` 指定，默认 `gpt-6-luna`。联网仍依赖有效的 `OPENAI_API_KEY` 和模型服务端点。网页搜索工具调用与模型 token 分别计费；当前接口不记录真实搜索费用。超时、无结果或服务异常返回错误，用户可重试。

## 验收口径

从项目根目录运行 `.\.venv\Scripts\python.exe -m pytest -q`，本次默认离线测试为 **33 passed**。假搜索和临时 SQLite 测试覆盖显式选择、默认空库 409、跨账号与 CSRF、网页引用持久化、无来源拒绝、搜索失败不写半轮，以及已索引知识库拒绝联网。前端脚本通过 Node 语法检查。2026-11-13 使用英文公开问题“What is the capital of France?”与中文公开问题“中国的首都是哪里？请给出来源。”各进行一次真实服务调用，分别返回 94 和 164 字符回答，均带 1 条网页来源；中文引用位置核对通过。这两次调用使用修改前的 Astra 默认值；改为 Luna 后仅验证了本地默认配置和 3 个联网搜索离线测试，未再产生付费搜索调用。没有记录费用，也未借此验证网页端显示。

待人工验证：浏览器中的网页引用位置与可点击链接、完整会话刷新恢复、无结果和服务错误表现，并记录调用量与费用。此前上传索引曾返回 401 `invalid_api_key`；这次联网调用成功不等于既有失败文档已重试或 Embedding 索引已恢复。完成浏览器端到端验收前不把本阶段标为完成。
