# 第十四阶段 离线评测与可观测性（进行中）

> [项目总览](../README.md) · [评测说明](../eval/README.md)

## 已接入

- `eval/corpus/` 与 `eval/dataset.jsonl`：五条人工标注的固定案例，覆盖直接问答、跨文档、指代追问、无答案和噪声干扰。
- `eval/metrics.py`、`eval/run_eval.py`：对同一次运行的预测文件计算文档级 `Hit@k`、`MRR@k`、引用准确率、无答案正确率、答案包含率、延迟分位数及模型调用次数；报告记录数据和预测文件哈希。
- `eval/collect_predictions.py`：在独立固定语料上运行现有 RAG 组件，默认使用 `gpt-6-luna` 采集预测；需要 API 密钥并产生费用，未在本次执行。
- `src/observability/http.py`：为 HTTP 响应加 `X-Request-ID`，记录请求方法、路径、状态码和耗时的 JSON 日志，不记录请求正文、Cookie 或密钥。
- `src/rag/rag_core.py`：结果元数据增加检索和回答阶段耗时。回答阶段包含证据审核、生成及聚合过程；现阶段不单独拆开每一次模型调用。
