# 第十二阶段 可选联网搜索（后端与页面已接入，真实服务调用通过）

> [项目总览](../README.md) · [上一阶段](第十一阶段-用户权限与会话持久化.md)

## 阶段目标与当前状态

登录后，输入框上方始终显示“联网搜索”按钮，默认关闭；点亮后可在新对话或任意本人历史会话中联网提问。没有选择知识库也可新建联网专用会话。后端用独立的 Responses API `web_search` 调用，网页回答和来源写入当前会话，刷新后仍可读取。关闭按钮后，同一会话可依据已保存且带来源的联网回答继续追问，不会自动重新联网；资料不够时仍使用原知识库范围或提示重新开启联网。离线回归及两次早期真实服务调用已通过；当前修复尚未进行真实模型端到端验收，因此本阶段是**部分完成**。

## 交互与数据边界

1. 输入框上方的联网按钮在所有已登录会话中可见，默认关闭。空库继续提示上传资料，`failed` 文档保留重试索引入口；点亮按钮后，即使没有知识库或当前库已有 `ready` 文档，也能联网提问。打开历史会话时按钮恢复关闭，用户可按需再次点亮。
2. 联网回答标明“网页来源”，把模型返回的引用位置显示为可点击链接，并列出网页标题与 URL；知识库回答继续使用本地文档片段。网页结果不自动写入知识库或 Qdrant。
3. 搜索请求通常只包含当前问题；“重新回答”等明确追问会附带同一会话的上一条用户问题，不发送私有文档或整段会话历史。后端按登录用户验证会话及知识库归属，网页来源类型、链接和引用位置随回答写入 MySQL；搜索失败不写入半轮消息。
4. 联网由每条消息的 `mode` 明确指定，不根据检索结果自动触发。知识库没有 `ready` 文档时，按钮关闭的知识库问答仍返回 409；已有文档但没有相关证据时，也不会自动联网。
5. 知识库模式先核查候选片段能否直接支持问题，并要求引用可在原文定位。资料不足时明确拒答，证据列表为空；用户可自行点亮联网按钮重问。首轮检索直接使用原问题，历史追问的改写不得输出占位符或改动问题中的人物、朝代和时间。
6. 关闭联网后，只从当前会话已保存的网页回答中找追问所需事实。答复继续附原网页链接并标记“未重新联网”；若没有可核对的历史网页回答，则回到原知识库流程。网页结果不自动写入文档库或向量索引。

## 实现与接口

- `src/chat/web_search.py` 调用 OpenAI Responses API 的 `web_search` 工具，同时读取 `url_citation` 和 `web_search_call.action.sources`。只有搜索来源而没有行内引用时，页面会为来源补可点击的行内链接；没有文字答案或有效 HTTP(S) 来源时返回明确错误。依据[官方 Web Search 文档](https://developers.openai.com/api/docs/guides/tools-web-search)中的两种来源结构。
- `POST /chat/sessions` 创建知识库会话使用 `{"knowledge_base_id":"..."}`，创建无知识库的联网专用会话使用 `{"session_type":"web"}`。新增迁移 `0004_web_only_sessions` 为 `chat_sessions` 加 `session_type`；既有记录默认为 `knowledge`，因此旧版全库会话仍可识别。
- `POST /chat/sessions/{id}/messages` 原请求 `{"message":"..."}` 默认知识库模式，但可先使用同一会话已保存的网页回答处理相关追问；显式联网使用 `{"message":"...","mode":"web"}`。请求仍需登录 Cookie 与 `X-CSRF-Token`。本人任意会话都可显式联网；未授权返回 404。联网专用会话没有可用网页上下文且按钮关闭时返回 409。
- 联网响应的 `evidence` 包含 `source_type=web`、`rank`、`title`、`url`，`metadata` 包含 `mode=web`、模型和引用位置 `citations`。网页只接受 HTTP(S) 来源链接。成功回答使用现有 `chat_messages` 保存，不新增数据库表。
- 页面在输入框上方显示联网按钮，点亮时改变颜色并设置 `aria-pressed=true`。回答正文中的引用与来源列表均可点击；浏览器创建链接时也只接受 HTTP(S) URL。网页引用与本地片段采用不同样式，刷新后由会话历史恢复。
- `WEB_SEARCH_MODEL` 可在 `.env` 指定，默认 `gpt-6-luna`。联网仍依赖有效的 `OPENAI_API_KEY` 和模型服务端点。网页搜索工具调用与模型 token 分别计费；当前接口不记录真实搜索费用。超时、无结果或服务异常返回错误，用户可重试。
