# 第六阶段 问答接口与前端

> 对应原模块 13～14 · [返回项目说明](../README.md) · [上一阶段](第五阶段-答案与证据聚合.md) · [下一阶段](第七阶段-多轮对话.md)

## 一眼看懂本阶段

这一阶段把命令行实验接入 FastAPI 和网页：应用启动时构建内存索引，浏览器可提问，接口返回回答与依据；另有 SSE 单轮流式接口。今天根路径看到的是第七阶段升级后的多轮界面。

| 项目 | 本阶段结果 |
| --- | --- |
| 目标 | 从控制台实验走向可在浏览器提问、查看答案与依据的原型 |
| 页面入口 | `GET /`，单页 HTML/CSS/原生 JavaScript |
| 单轮接口 | `POST /ask` 和 `GET /ask/stream` |
| 启动资料 | `data/model12/*.md`，启动时向量化后写入内存 |

本阶段让前五阶段的问答链路能通过 HTTP 调用。页面后来升级为多轮对话样式，因此今天打开根路径看到的是第七阶段完成后的界面，而不是旧版单轮结果页。

## 具体完成的工作

### 服务启动与普通问答

`app/rag_app.py` 创建 Markdown Loader、清洗器、语义切分器、Embedding、内存库、检索器、Embedding 重排器、PromptBuilder、模型和答案感知聚合器。`app/main.py` 的 lifespan 在服务启动时对待入库片段做 Embedding 并填充内存库。`POST /ask` 接收 JSON `query`，返回完整 `answer`、`evidence` 和 `metadata`。

### 单轮流式接口

`GET /ask/stream?query=...` 使用 SSE 发送 `answer_chunk`，最后发送状态为 `Done` 的事件和证据、元数据。`RAGCore.stream_answer_with_result()` 在同一次检索与回答中产出文本和最终结果，路由不再为获取证据重新调用 `answer()`。未配置聚合器时，文本来自模型真正的增量生成；当前 Web 配置了聚合器，它先完成综合回答，再把完整文本分块发送，因此这里的“流式”不等于模型逐 token 实时输出。原前端曾通过 `EventSource` 逐步显示文本；当前页面主路径使用 `/chat` 完成多轮问答，这个单轮接口仍可直接调用。

## 文件与职责

| 文件 | 作用 |
| --- | --- |
| `app/rag_app.py` | 当前 Web 使用的组件配置及示例文档读取 |
| `app/main.py` | 应用生命周期、HTTP 路由、SSE 响应 |
| `app/templates/index.html` | 页面布局、输入和每轮结果显示 |
| `src/rag/rag_core.py` | 普通与流式模型生成路径 |

## 请求与数据流

```text
启动：data/model12/*.md → 切分 → Embedding → InMemoryVectorStore
单轮：query → /ask → RAGCore.answer() → answer + evidence + metadata
流式：query → /ask/stream → answer_chunk 事件 → Done 事件
```

根路径 `/` 从 `app/templates/index.html` 返回页面。`app/rag_app.py` 只扫描 `data/model12/*.md`；`main.py` 的 lifespan 将待入库片段计算 Embedding 后填入内存库，并建立聊天服务。启动阶段失败时，页面也不能提供问答。

## 接口和页面

| 路由 | 请求 | 成功响应 |
| --- | --- | --- |
| `POST /ask` | JSON `query` | `answer`、`evidence[]`、`metadata` |
| `GET /ask/stream` | 查询参数 `query` | SSE：多个 `answer_chunk`，最后 `status=Done`、回答、证据、元数据 |
| `GET /` | 无 | 当前单页对话界面 |

证据项包含 `rank`、`score`、`source`、`chunk_id`、`content`。SSE 按默认 `message` 事件发送 JSON，旧页面使用 `EventSource` 接收；当前页面不调用该路由，而调用第七阶段的 `/chat`。FastAPI 另提供 `/docs` 自动接口文档。

## 验证与限制

原模块 13、14 记录了页面运行前、中、后的截图；本次文档不保留截图。已用假检索器、聚合器和模型做无密钥回归，验证 SSE 文本与最终回答一致、只召回和聚合一次；尚未启动真实模型或进行浏览器端到端测试。当前没有网页上传或任意目录切换。
