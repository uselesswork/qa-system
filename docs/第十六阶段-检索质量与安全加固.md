# 第十六阶段：检索质量与安全加固

> [返回 README](../README.md) · [评测说明](../eval/README.md)

## 本阶段交付

- **固定评测**：新增独立的 [`eval/stage16/`](../eval/stage16/) 语料和 10 条标注问题，覆盖跨文档、相似项目、过时草案、日期区分、无答案与恶意指令。采集脚本支持独立语料和临时本地 Qdrant，输出记录模型与向量后端；评分报告可记录逐文件语料哈希。旧五条样本和原基线保持不变。
- **证据边界**：知识库原有的先审核原文摘录、再生成答案、无证据拒答流程继续使用。审核和生成提示词明确把上传内容视为不可信资料；Markdown 长章节切成最多 500 字符的片段，防止单个标题下的正文无限进入模型上下文。
- **上传边界**：同步与异步上传共用文件名、扩展名和内容预校验：拒绝路径和控制字符、空文件、超过 10 MiB 的文件、伪装 PDF、非 UTF-8 或含 NUL 的文本。提取文字最多 500000 字符，索引片段最多 1200 条，PDF 最多 120 页。无法提取文字的文件仍会拒绝；异步 PDF 深度解析失败会进入 `failed` 任务状态。
- **调用边界**：配置了 `REDIS_URL` 时，各 Web 实例共享按账号的固定窗口计数；知识库问答每账号每小时最多 120 次，联网搜索 20 次，上传 20 次；注册每来源 IP 每小时 10 次、登录 60 次。超限返回 `429` 与 `Retry-After`，Redis 不可用时返回 `503`，不会继续发起受保护的付费请求。问答输入上限 2000 字符。没有配置 Redis 的单进程实验模式不启用限流。

## 检索策略决定与限制

当前扩展样本没有显示关键词召回或重排的具体失败，**暂不引入混合检索**。既有证据审核提供引用原文校验和无证据拒答；提示词边界及一条注入样本通过不代表能抵御任意提示词注入。限流限制请求次数，不等于精确的货币支出上限；模型供应商价格、单次生成长度和真实费用仍需单独计量。PDF 页数和提取字符的限制不能替代隔离解析进程或恶意 PDF 专项测试。公网部署、负载测试、真实多实例限流和浏览器端的阶段 16 专项验收仍未完成。
